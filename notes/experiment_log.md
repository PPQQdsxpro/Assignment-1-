# 探索與修正紀錄

1. 初跑使用 jieba HMM=False，僅固定「家珍」。初步得到 62 / 76 / 110 個合格搭配詞（五詞、十詞、句子）。
2. 分詞抽查發現「凤霞」「有庆」「福贵」「二喜」等姓名被拆為單字，會受到最少兩字篩選影響；這些結果不能直接用作主要文學論證。
3. 修正為 HMM=True，並固定家珍、福贵、凤霞、有庆、二喜、苦根、春生、龙二、老全、长根十個姓名為完整詞。這是分詞品質修正，不是為取得顯著結果而更改 p 門檻。
4. 用同一份修正後語料依序重跑五詞、十詞、句子。正式合格結果為 78 / 107 / 141；三組皆使用 p<.05、至少兩字與同一停用詞清單。
5. 姓名修正後共有 49,097 詞、2,411 句；短句規則排除三次家珍姓名，保留577次。初跑數據與最終數據不得混用。
6. 獨立 Python 計數驗證正式結果的觀察值、全局次數及期望值；使用 SciPy 重算 Fisher 單尾 p 值。qhchina 編譯計算與 SciPy 存在約10^-10絕對誤差，最大低於10^-9，顯著性判斷一致。
7. 三组前20名比較只說明排名集合變化。某詞沒有進入前20，不等於完全不顯著；「凤霞」在五詞視窗 p≈0.08858，才是確實未通過門檻的案例。
